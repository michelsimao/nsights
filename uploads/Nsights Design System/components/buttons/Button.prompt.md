Flat editorial button; use `primary` for the single main action, `secondary` for everything else, `ghost` inline, `gold` only for premium upsells.

```jsx
<Button variant="primary">Gerar relatório</Button>
<Button variant="secondary" size="sm">Cancelar</Button>
```

Variants: primary (solid accent, no gradient), secondary (transparent + hairline border), ghost (accent text, tint hover), gold (gold gradient). Sizes: md (10×20px), sm.
