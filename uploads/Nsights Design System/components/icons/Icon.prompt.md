Lucide glyph at hairline 1.75px stroke — the Nsights icon treatment. Inherits `currentColor`; size 14–18px in UI.

```jsx
<Icon name="shield-check" size={16} />
<Button variant="secondary"><Icon name="download" size={14} /> Exportar</Button>
```

Loads the Lucide library once from CDN; renders an empty placeholder of the same size until loaded. Use kebab-case Lucide names (`scale`, `landmark`, `file-check`, `gavel`, `fingerprint`, …). Never mix with emoji or filled icon sets.
