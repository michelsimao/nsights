Fundação · Superfícies e motion

Flat, com borda de 1px

O sistema não empilha sombras: superfícies se separam por cor + borda 1px (--border #ded9e2, --border-strong #cfc7d5). Sombra é exceção com papel definido, e o movimento é curto — .12 a .2s — com um easing próprio só para o shell.

O fundo e o topbar

O body não é chapado: um radial-gradient roxo a 5,5% de opacidade nasce fora do canto superior direito e morre em 28rem — este cartão está sobre ele. O topbar não tem sombra: a profundidade vem de fundo translúcido + blur, fechado por border-bottom.

background:
  radial-gradient(circle at 78% -12%, rgba(112, 36, 199, .055), transparent 28rem),
  var(--surface);                                          /* globals.css:32–34 */

.topbar { backdrop-filter: blur(14px); background: rgba(255, 255, 255, .9);
  border-bottom: 1px solid var(--border); }                /* globals.css:67 */
Achado — a pauta pedia "a sombra do topbar", mas o topbar real não declara box-shadow nenhuma: é blur + translucidez. Registrado como está no arquivo.

A regra da casa: reduced-motion sempre honrado

Um bloco global zera tudo, e sete regras pontuais tratam os casos que precisam de nuance (o spin que desacelera em vez de sumir; o typewriter do login que já nasce revelado).

@media (prefers-reduced-motion: reduce) {                       /* globals.css:1114–1118 */
  html { scroll-behavior: auto; }
  *, *::before, *::after { animation-duration: .01ms !important;
    animation-iteration-count: 1 !important; scroll-behavior: auto !important;
    transition-duration: .01ms !important; }
  .auth-typewriter-line { border-right-color: transparent; grid-template-columns: 1fr; }
}

Regras pontuais em globals.css:212, 334, 690, 3286, 3365, 3511 e 3711 — nenhuma animação do produto escapa da preferência do usuário.
